## Timeline

The Shai-Hulud campaign began on September 16, 2025 [Source: https://www.cisa.gov/news-events/alerts/2025/09/23/widespread-supply-chain-compromise-impacting-npm-ecosystem]. The initial attack involved malicious versions of popular npm packages being published to the registry. These packages contained a post-install script that harvested sensitive data and exfiltrated it to attacker-controlled public GitHub repositories named "Shai-Hulud" [Source: https://unit42.paloaltonetworks.com/npm-supply-chain-attack/][Source: https://www.wiz.io/blog/shai-hulud-npm-supply-chain-attack].

By September 17, 2025, researchers identified over 500 compromised packages across multiple developers' accounts including @ctrl users (deluge, golang-template, magnet-link) and various Angular/NativeScript community packages with version pairs indicating malicious updates [Source: https://www.stepsecurity.io/blog/ctrl-tinycolor-and-40-npm-packages-compromised][Source: https://socket.dev/blog/ongoing-supply-chain-attack-targets-crowdstrike-npm-packages]. The attack leveraged a self-replicating worm mechanism that automatically spread when encountering additional npm tokens in victim environments [Source: https://unit42.paloaltonetworks.com/npm-supply-chain-attack/][Source: https://www.wiz.io/blog/shai-hulud-npm-supply-chain-attack].

On November 25, 2025, Unit 42 researchers documented "Shai-Hulud 2.0," an escalated campaign affecting tens of thousands of GitHub repositories including over 350 unique users [Source: https://www.microsoft.com/en-us/security/blog/2025/12/09/shai-hulud-2-0-guidance-for-detecting-investigating-and-defending-against-the-supply-chain-attack]. This phase introduced execution during the pre-install phase rather than post-install, dramatically widening impact across CI/CD pipelines and eliminating reliance on human interaction for malware execution [Source: https://www.microsoft.com/en-us/security/blog/2025/12/09/shai-hulud-2-0-guidance-for-detecting-investigating-and-defending-against-the-supply-chain-attack].


By May 2026, a "Mini Shai-Hulud" resurgence was detected in late April affecting approximately 170 npm packages plus PyPI targets [Source: https://www.microsoft.com/en-us/security/blog/2025/12/09/shai-hulud-2-0-guidance-for-detecting-investigating-and-defending-against-the-supply-chain-attack]. Microsoft Defender reported protection coverage beginning around this time.

## How it Spreads

The attack chain follows a multi-stage propagation model: Initial access was gained through credential-harvesting phishing campaigns spoofing npm login prompts asking developers to "update" MFA options. Once initial compromise occurred, the threat actor deployed malware scanning for sensitive credentials including .npmrc files and cloud service API keys (AWS, GCP, Azure) [Source: https://www.cisa.gov/news-events/alerts/2025/09/23/widespread-supply-chain-compromise-impacting-npm-ecosystem][Source: https://unit42.paloaltonetworks.com/npm-supply-chain-attack/.

The worm's self-propagation mechanism works by authenticating as compromised developer accounts on npmjs.com registry. Using stolen tokens, it identifies other packages maintained by those developers, injects malicious code into them, and publishes the new versions to the public registry without direct actor intervention—achieving exponential spread [Source: https://www.cisa.gov/news-events/alerts/2025/09/23/widespread-supply-chain-compromise-impacting-npm-ecosystem][Source: https://unit42.paloaltonetworks.com/npm-supply-chain-attack/.

Shai-Hulud 2.0 introduced a more aggressive fallback mechanism: if credential theft failed or exfiltration channels were unavailable, malware attempts destructive sabotage by securely overwriting every writable file in victim's home directory using shred commands [Source: https://www.microsoft.com/en-us/security/blog/2025/12/09/shai-hulud-2-0-guidance-for-detecting-investigating-and-defending-against-the-supply-chain-attack]. New payload files (setup_bun.js and bun_environment.js) execute during the pre-install phase of npm packages, bypassing static scanning tools that inspect code at later build stages [Source: https://www.microsoft.com/en-us/security/blog/2025/12/09/shai-hulud-2-0-guidance-for-detecting-investigating-and-defending-against-the-supply-chain-attack].

The attack also leveraged GitHub impersonation tactics with commits signed under "Linus Torvalds," the Linux kernel creator. This fake persona technique complicates forensic attribution and requires additional verification through commit signature checks to confirm actual authorship [Source: https://www.microsoft.com/en-us/security/blog/2025/12/09/shai-hulud-2-0-guidance-for-detecting-investigating-and-defending-against-the-supply-chain-attack].

## Remediation steps

Organizations should immediately conduct dependency reviews of all npm-based software, checking package-lock.json or yarn.lock files for affected packages including nested dependencies in the tree structure [Source: https://www.cisa.gov/news-events/alerts/2025/09/23/widespread-supply-chain-compromise-impacting-npm-ecosystem]. Search cached versions of compromised dependencies across artifact repositories and dependency management tools. Pin package version constraints to known safe releases published prior to September 16, 2025 (for original campaign) or December 9, 2025 (for Shai-Hulud 2.0 phase) [Source: https://www.cisa.gov/news-events/alerts/2025/09/23/widespread-supply-chain-compromise-impacting-npm-ecosystem][Source: https://unit42.paloaltonetworks.com/npm-supply-chain-attack/.

Rotate all developer credentials immediately including GitHub Personal Access Tokens (PATs), npm tokens, SSH keys, API keys for cloud services, and environment variable secrets that may have been exposed in compromised repositories [Source: https://www.cisa.gov/news-events/alerts/2025/09/23/widespread-supply-chain-compromise-impacting-npm-ecosystem][Source: https://unit42.paloaltonetworks.com/npm-supply-chain-attack/. Mandate phishing-resistant multifactor authentication on critical platforms like GitHub and npm accounts. Monitor network behavior by blocking outbound connections to webhook.site domains and suspicious external hosts; review firewall logs for anomalous activity [Source: https://www.cisa.gov/news-events/alerts/2025/09/23/widespread-supply-chain-compromise-impacting-npm-ecosystem][Source: https://unit42.paloaltonetworks.com/npm-supply-chain-attack/.

Harden security posture through removing unnecessary GitHub Apps, auditing repository webhooks and secrets, enabling branch protection rules, activating GitHub Secret Scanning alerts, and configuring Dependabot automated security updates. For Shai-Hulud 2.0 specifically, verify commit signatures to detect impersonation attacks by Linus Torvalds-style fake personas [Source: https://www.cisa.gov/news-events/alerts/2025/09/23/widespread-supply-chain-compromise-impacting-npm-ecosystem][Source: https://unit42.paloaltonetworks.com/npm-supply-chain-attack/.
